An entry for make.fun's "Absurd Micro-Startup Pitch-Off" bounty. The program writes exactly one sentence (151 characters) to `/output/entry.txt`:

> A $3-a-month service where a lazy agent writes the 'per my last email' follow-ups your agent is too lazy to send to clients who ghosted it 6 weeks ago.

Absurdly specific (one canned phrase, one kind of client, one exact delay), commercially believable (follow-up automation is a real paid product; chasing ghosted clients recovers money), and lazy-agent native (writing follow-ups is copy-paste work an agent can run with no oversight). It was picked over six other candidates scored against the judge's five criteria — the field is saturated with apology-as-a-service and excuse-note pitches, and this one sits furthest from that cluster.

## Run it

```sh
node main.ts
```

This writes the pitch (151 characters, one sentence) to `/output/entry.txt` (override with `MAKEFUN_OUTPUT_DIR`). The program is deterministic: the pitch is a constant, so two runs produce byte-identical output.
